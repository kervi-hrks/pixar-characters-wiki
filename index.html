Sobre esta base

Um catálogo local, ligado à fonte.

Os nomes, resumos, imagens e categorias são obtidos da API MediaWiki da Pixar Cars Wiki. Cada ficha mantém um link para a página original.

Este projeto não é afiliado à Disney, Pixar ou Fandom. O conteúdo comunitário da wiki é disponibilizado sob CC BY-SA; imagens podem ter licenças próprias.

Atualização

No Windows, execute atualizar-dados.ps1 dentro da pasta do site. Ele recria characters.json consultando a API e preserva a organização por categorias.
